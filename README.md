# BipolTrack — Suivi de traitement bipolaire

Application PWA de suivi de traitement bipolaire, installable sur iPhone via Safari.

## 🚀 Installation sur GitHub Pages

1. Créer un dépôt GitHub public nommé `bipoltrack`
2. Uploader les 3 fichiers : `index.html`, `manifest.json`, `sw.js`
3. Aller dans **Settings → Pages → Source: main / root → Save**
4. Votre URL : `https://[pseudo].github.io/bipoltrack/`

## 📱 Installation sur iPhone

1. Ouvrir l'URL dans **Safari**
2. Bouton **Partager** (carré avec flèche)
3. **"Sur l'écran d'accueil"**
4. L'app fonctionne hors-ligne grâce au Service Worker

## Fonctionnalités

- Journal quotidien (humeur 1–10, sommeil, anxiété, symptômes, effets secondaires)
- Gestion des traitements
- Statistiques & graphiques
- Génération de rapport médecin
- Stockage 100% local (localStorage)
- Fonctionne hors-ligne (PWA)
